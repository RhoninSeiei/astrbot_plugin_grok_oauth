# 常见问题

## Grok 4.7 支持音频吗

官方 Grok 4.7 是文本和图片输入、文本输出。当前插件不支持 `audio_urls`、音频转录、语音合成或实时语音；原生模型设置里的音频复选框属于通用控件，勾选不会增加协议能力。

可通过 AstrBot 另外配置的语音识别服务先转换为文字，再让 Grok 对话；语音回复则另接语音合成服务。这是宿主的组合流程。xAI 的独立语音服务能否使用订阅 OAuth，仍需单独验证。[Grok 4.7](https://docs.x.ai/developers/grok-4-7) · [实时语音](https://docs.x.ai/developers/model-capabilities/audio/speech-to-speech)

## 为什么提供商源还有 API Key 字段

AstrBot 的通用提供商源编辑器可能显示该字段，留空即可。已有配置中的 `oauth-managed` 是占位值，无需填写。OAuth 令牌由插件独立保存；模型条目应显示模型能力、上下文和自定义参数。旧模型菜单异常时，确认使用当前插件版本并刷新页面。

## 登录后为什么还不能聊天

授权成功说明账号绑定完成，仍需添加模型并在目标会话选择它。检查实际模型名和提供商 ID、账号对应权限、代理与出站网络。`grok-4.7-build-fast` 是 Build 渠道变体，目录中出现不代表所有账号可用；插件不会偷偷改用其他模型或 API Key。

默认聊天型号仍保留 `grok-4.6` 以兼容既有配置；新配置可以明确选择 `grok-4.7`。已保存的 ID 中含旧版本号，也可能实际请求新型号，应以模型名称字段为准。

## 额度未知、403 或 429 分别是什么

未知表示缺少可解释的数据，不等于没有余额。403 表示额度接口拒绝访问，不自动解除聊天绑定。429 表示限流，等待冷却后再试，连续刷新不会绕过限制。额度查询与聊天使用不同上游入口，聊天可用不保证额度接口当时可用。

共享额度百分比不换算成固定 token、图片或视频数量。消耗来源按上游原值显示；缺失来源保持未知，不补成零。上游总量与来源百分比不一定采用相同统计口径，应结合页面采集时间和状态解读。

## 为什么群里不能查询额度

默认群白名单为空。管理员配置完整 `unified_msg_origin` 后，普通成员可通过 Grok 模型工具查询；直接命令仍仅管理员可用。其他模型不具备额度工具调用权限。

## 为什么搜索或图片工具没有出现

检查插件能力与工具开关、当前模型来源，以及 AstrBot 的工具选择和人格设置。默认仅 Grok 模型可使用；管理员可以给搜索和图片分别指定跨模型实例。模型按需决定是否搜索，普通聊天不会自动先搜索。

## 图片生成成功但没有收到附件

先核对消息平台的发送限制和插件返回的操作状态。保留操作 ID，在原会话使用 `/grok_image_resend <operation_id>` 重发已有图片。发送状态不确定时不会自动重新生成，以免重复消耗额度。实际附件交付仍需按所用平台验证。

## 聊天能直接读取 GIF 动画吗

Grok 4.7 在当前 OAuth `/v1/responses` 聊天路径中实测拒绝 GIF 原文件，插件也不提供 GIF 转码或抽帧。相同内容的 PNG 实测可用；本插件图片输入接受 PNG、JPEG 和 WebP。将 GIF 转为单张图片只能分析该帧，不能代表完整动画理解；需要分析动态变化时，应由调用端先抽取并标注多帧。

## 视频生成完成后为什么没有附件

本插件的视频工具和公共 Provider 方法只负责提交、查询、下载与读取，不自动通知或发送。调用插件需要保存任务 ID、等待完成、读取 MP4 bytes，再通过自身消息渠道发送。三个 Agent 视频工具返回任务信息，默认工具循环不会自动补上视频附件。QQ群的已验证标准发送示例见[开发 API](API.md#已验证的qq发送方法)。

## 能使用来源视频加人设参考图编辑角色吗

当前不支持视频与参考图联合编辑。视频编辑接受来源视频与文字提示词；参考图生成新视频属于另一种能力，不能用来承诺保留原视频动作和场景的角色替换。本插件在提交前明确拒绝联合输入，不丢弃参考图或改用图生视频。

## 如何更新和报告问题

使用 AstrBot 插件更新流程，保留插件数据目录及配置。报告插件版本、AstrBot 版本、实际模型名、复现步骤和经过脱敏的错误摘要。不要上传令牌、认证码、代理密码、完整配置或未经检查的日志。安全问题见[漏洞报告](../SECURITY.md)。
