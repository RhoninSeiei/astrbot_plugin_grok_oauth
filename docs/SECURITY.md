# 安全与数据边界

## 认证

凭据保存在 AstrBot 插件数据目录 `astrbot_plugin_grok_oauth/credentials.json`。文件权限为0600，凭据目录由单一进程持有生命周期锁；多模型实例共享一次刷新。新令牌先原子持久化，再发布内存版本。轮换后的持久化失败阻断旧令牌重用；解绑和关闭通过epoch隔离，重新绑定额外增加binding_generation；刷新成功与失败均检查启动代次，避免版本号重新使用时接收旧账号结果。

授权与令牌只发送到经过校验的 `auth.x.ai`，推理 Bearer 只发送到 `api.x.ai:443`。独立额度客户端另允许固定 `https://cli-chat-proxy.grok.com/v1/billing?format=credits` 的GET，携带由本插件OAuth令牌端点或现有用户access token严格匹配声明取得的私有身份字段；不扩大推理客户端白名单。重定向关闭，HTTP路径受限，认证失效不会读取XAI_API_KEY回退。401最多进行一次同一授权代际的恢复；新绑定不会接管旧请求。

授权管理命令同时检查管理员权限和私聊属性；额度命令允许额外配置群会话白名单，但仍要求管理员。Dashboard API使用真实宿主JWT鉴权与管理员身份，流程状态和取消操作验证所有者。公开CLI客户端资格与账号模型权限分别验证，未运行的能力保持unknown。

## 媒体

资产包含随机ID、真实格式、哈希、平台实例、UMO、conversation ID及到期信息。跨会话读取统一拒绝。默认单图20MiB、4000万像素、每批80MiB解码预算，资产默认保留7天、容量2GiB。当前实现通过操作准入和租约保护清理；删除仅限本插件管理文件。

本地路径要求允许根目录，使用实际目录文件描述符与禁止符号链接跟随的打开流程。网络下载默认关闭；显式白名单路径使用无OAuth的客户端，DNS结果必须为公网IP，连接固定该IP并保留原主机TLS验证。禁用跨请求连接复用以避免不同逻辑主机共享固定IP连接。重定向逐次验证，读取有大小与时间限制。

图像和磁盘工作采用有界线程；关闭和取消必须等待已开始写入完成或一致回滚。媒体生成接受后的超时、断流等记录OutcomeUnknown，不自动重新生成。

## 交付与历史

`generate_image` 只生成和保存。Agent工具负责附件交付，模型只收到简短状态与资产句柄。outbox先记录操作，再生成与发送；同一消息中重复有效请求复用已有记录。发送回执不确定时保持unknown；显式重发只使用原资产。

本插件生成的日志和工具摘要不记录token、完整上游响应、base64图片或服务器路径。输入视觉消息的保存方式由宿主控制，宿主可能在消息历史中保存输入图片的data URI；本插件不改变宿主历史存储策略。推理协议状态通过宿主reasoning_signature保留，不用于存放图像或认证数据。`store:false`仅控制Responses会话存储，不是服务商所有数据零保留的声明。

升级前备份配置与插件数据，通过 AstrBot 的目标插件安装或更新流程操作。测试使用隔离状态，不复用真实账号或运行数据。


## 网页搜索边界

搜索仅通过既有OAuth传输访问固定xAI推理端点。调用方的查询和指定域名发送给xAI，来源网页由xAI检索；插件不跟随来源链接、不转发OAuth头至来源站点。工具结果是外部证据，不能作为系统或开发者指令。摘要、来源数量和URL长度有界，使用统计采用字段白名单，错误消息不包含上游正文。

`oauth_web_search=disabled` 会移除本插件搜索入口并拒绝未授权的搜索函数返回。普通聊天不预搜索；没有跨消息的搜索结果缓存。与Codex工具保持独立命名和对象所有权，不改变其启用状态。搜索域名筛选不改变图片下载白名单。


注册的搜索和图片工具默认核验调用是否由当前插件的Grok Provider实际产生。校验附着于原始Python字符串参数，仅保留Provider弱引用、工具名、参数摘要和一次性状态；不携带OAuth凭据，不进入JSON、日志文本或会话历史。复制共享消费状态，参数修改、跨工具使用、过期、已消费及Provider关闭均拒绝；没有来源证明时只能使用管理员明确配置的跨模型实例。

这约束模型发出的注册工具调用，不试图隔离同进程中的可信插件代码。直接Provider SDK仍是显式程序接口。自建非Grok Agent绕过准备钩子时，应自行提供允许的工具集合；通用搜索策略不一定跨过该核心SDK路径传递到工具handler。


## 额度边界

额度工具允许普通用户使用，强制要求Grok来源；群会话仍需白名单，其他模型不可调用。管理员命令和Dashboard权限不变。权限在缓存和上游之前检查。空参数工具的一次性证明附于工具名，参数仍为空对象；请求工具集合及证明绑定当前授权代次，旧响应不能跨换绑使用。未准备的全局执行器一律拒绝；不存在额度跨模型例外，已消费或失效的Grok证明始终拒绝。

额外user_id仅写入0600凭据存储，不返回页面、模型或日志；额度仅输出字段白名单。账务403不解除聊天绑定，不返回旧快照；未知值不解释为零。429冷却、120秒共享缓存和最长10分钟历史快照均由后端控制，历史快照不得跨授权或已知周期终点，页面请求失败清除旧显示。解绑与关闭使在途结果失效，服务关闭取消并等待所有额度任务。


0.4.1的访问令牌身份回退只读取本插件已有凭证：固定issuer、匹配client_id、User主体、principal_id与sub一致且字段别名不冲突。该读取用于请求路由，不代替上游Bearer签名验证，不接受模型提供的身份字段；不对Team或未知主体猜测用户ID。旧绑定无需写入或重新登录即可查询，401刷新后重新计算身份，缺失则停止重试。

## 日志来源与独立调试文件

插件的原生日志只经 `astrbot.api.logger` 或宿主提供的插件日志入口输出。协议层不创建日志器，不操作 `httpx/httpcore` 日志器，也不设置全局过滤器。第三方库自行产生的请求日志由宿主管理，可能包含媒体 URL 和签名参数；本插件独立调试文件不是对第三方日志的重定向或拦截。

`transport_debug_file` 默认关闭。开启后，仅将字段白名单内的阶段、状态、耗时、计数及安全标识写入插件数据目录下的 `debug/transport.jsonl`，不保存凭据、正文、原始异常和完整链接。文件权限为 `0600`，最多当前文件与一个轮转备份，各 1 MiB。有界队列拥塞时允许丢弃诊断记录；诊断输出失败不改变业务请求结果。
